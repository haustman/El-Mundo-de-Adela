# Resources

Carpeta especial de Unity. Los assets acá se cargan desde código con `Resources.Load()`.

- **cielo.png** — Imagen de fondo del cielo. Se carga desde `CameraController.cs` para crear el fondo del juego.
- **DOTweenSettings.asset** — Configuración de DOTween (legacy, se puede borrar si DOTween no se usa).

No meter cosas acá a menos que las necesites cargar desde un script.
