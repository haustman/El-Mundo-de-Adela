## Siguiente paso (cuando se pida)
1. Elegir PNGs a usar
2. Importar a Unity con Pixel Perfect (PPU según tamaño)
3. Slice sprites (Grid by Cell Size o Automatic)
4. Crear Tile Palette y pintar en Tilemap de daño
5. Añadir collider de trigger + script de daño
