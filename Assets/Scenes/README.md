# Scenes

Escenas del juego.

- **Menu.unity** — Pantalla de menú principal (índice 0 en Build Settings). Logo con efecto de parpadeo, botones Jugar y Salir con sombra y escala al hover, transición con fade a negro al jugar.
- **SampleScene.unity** — Nivel de juego (índice 1 en Build Settings). Jugador, enemigos, tilemaps, cámara, UI, etc.

Si agregás más escenas, acordate de agregarlas en Build Settings.
